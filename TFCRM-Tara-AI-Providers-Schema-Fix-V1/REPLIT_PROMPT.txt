Repository:

Patch folder:
TFCRM-Tara-AI-Providers-Schema-Fix-V1

المشكلة مؤكدة: tara_ai_providers موجود بالـ Legacy Schema: id, provider, enabled, config_json, updated_at و ROW_COUNT=0.

1) cd /tmp && rm -rf tfcrm-patchs && git clone --depth 1 https://github.com/mohamedamouseo-a11y/tfcrm-patchs.git
2) cp /tmp/tfcrm-patchs/TFCRM-Tara-AI-Providers-Schema-Fix-V1/apply_tfcrm_tara_ai_providers_schema_fix_v1.mjs /var/www/TFCRM/
3) cd /var/www/TFCRM
4) DRY RUN: node apply_tfcrm_tara_ai_providers_schema_fix_v1.mjs

لا تكمل إلا لو ظهر: SCHEMA_STATE=LEGACY_EXACT و ROW_COUNT=0 و RESULT=DRY_RUN_PASS.

5) APPLY: node apply_tfcrm_tara_ai_providers_schema_fix_v1.mjs --apply

مسموح ALTER واحد فقط على tara_ai_providers لتحويله للـ schema الحالية وإزالة config_json لأن الجدول فارغ. ممنوع CREATE/DROP TABLE، INSERT/UPDATE/DELETE، db:push، migrations عامة، تشغيل scripts/apply-tara-multi-provider-v1-migration.ts، تعديل سورس، build، tsc، PM2 restart، Docker/Evolution restart، أو أي Provider API call.
