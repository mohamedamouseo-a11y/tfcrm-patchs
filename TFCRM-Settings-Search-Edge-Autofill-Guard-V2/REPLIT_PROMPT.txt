المشكلة:
Microsoft Edge ما زال يحقن البريد المحفوظ داخل Search Settings بعد Reload حتى بعد autocomplete=off وreadOnly، وبعد التأكد أن Production Build وRestart تم تنفيذهما.

نفّذ فقط:
1) cd /tmp && rm -rf tfcrm-patchs && git clone --depth 1 https://github.com/mohamedamouseo-a11y/tfcrm-patchs.git
2) cd /tmp/tfcrm-patchs/TFCRM-Settings-Search-Edge-Autofill-Guard-V2
3) python3 APPLY_PATCH.py /var/www/TFCRM
4) cd /var/www/TFCRM
5) npm run build
6) حدّد PM2 process/ processes التي pm_cwd الخاص بها يساوي /var/www/TFCRM بالضبط، واعمل Restart لها فقط.
7) تأكد أنها online.
