المطلوب من Phase 3:
- Autocomplete/Suggestions داخل Search الخاص بـ Client Pool.
- يبدأ بعد كتابة حرفين على الأقل.
- يعرض بحد أقصى 6 اقتراحات.
- يستخدم نفس نتائج accountManagement.listClients الحالية، بدون API جديد وبدون Query إضافي منفصل للاقتراحات.
- الاقتراحات لازم تحترم نفس permissions/team/account-manager scope والفلاتر الحالية.
- Phase 1 normalization وPhase 2 fuzzy يفضلوا كما هم بدون تغيير.
- اختيار الاقتراح يملأ نفس search input ويشغّل نفس Smart Search.
- دعم Mouse.
- دعم Keyboard: ArrowDown / ArrowUp / Enter / Escape.
- أثناء انتظار debounce/fetch يظهر Loading suggestions بدل بيانات قديمة.
- لا تعرض contactEmail/phone كـsecondary text في قائمة الاقتراحات؛ استخدم businessProfile/leadName/group/accountManagerName فقط.

اختبر بعد النشر:
1) افتح Client Pool.
2) اكتب حرف واحد: لا تظهر Suggestions.
3) اكتب حرفين أو أكثر من اسم عميل/شركة موجودة: تظهر الاقتراحات.
4) جرّب Search صحيح ثم typo بسيط وتأكد أن Phase 2 مازال يعمل.
5) اختر اقتراح بالماوس وتأكد أن الحقل يتم ملؤه والنتائج تتحدث.
6) جرّب ArrowDown ثم Enter.
7) جرّب Escape لإغلاق القائمة.
8) جرّب Account Manager أو role محدود وتأكد أن الاقتراحات لا تعرض أي عميل خارج scope.
9) تأكد أن تغيير filters يغيّر suggestions بنفس الـscope الحالي.

لو Build أو الاختبار فشل، لا تعمل Fix إضافي تلقائيًا. ارجع بالناتج كامل.
