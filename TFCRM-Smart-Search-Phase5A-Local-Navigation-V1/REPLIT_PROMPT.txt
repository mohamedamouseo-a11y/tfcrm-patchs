نفّذ فقط:
1) cd /tmp && rm -rf tfcrm-patchs && git clone --depth 1 https://github.com/mohamedamouseo-a11y/tfcrm-patchs.git
2) cd /tmp/tfcrm-patchs/TFCRM-Smart-Search-Phase5A-Local-Navigation-V1
3) python3 APPLY_PATCH.py /var/www/TFCRM
4) cd /var/www/TFCRM
5) NODE_OPTIONS=--max-old-space-size=3072 npm run build
6) بعد نجاح Build فقط، حدد PM2 process التي pm_cwd = /var/www/TFCRM بالضبط واعمل Restart لها فقط.
7) تحقق online وHTTP 200.

المطلوب التحقق منه Live:
A) Navigation/Menu Search:
- افتح القوائم.
- عربي: ابحث باسم قائمة بألف مختلفة/تشكيل أو typo بسيط؛ لازم يفلتر بشكل صحيح.
- English: جرب case مختلف وtypo بسيط.
- زر Mic يظهر إذا browser يدعم SpeechRecognition.
- Voice transcript يدخل نفس menuSearch.
- القائمة نفسها تعتبر live suggestion set permission-aware لأنها مبنية أصلًا من الروابط الظاهرة للمستخدم؛ لا تضف روابط خارج صلاحياته.

B) Settings Search:
- تأكد أن Edge Autofill bug لم ترجع وأن البريد لا يُحقن بعد Ctrl+F5.
- Arabic normalization وEnglish case-insensitive شغالين.
- typo بسيط يجيب Tab قريب.
- بعد حرفين تظهر بحد أقصى 6 Suggestions من Settings tabs المسموح بها فقط.
- اختيار Suggestion يملأ البحث.
- Mic يظهر إذا مدعوم وVoice transcript يدخل نفس settingsSearch.

C) Regression:
- Client Pool P1/P2/P3/P4 تظل شغالة.
- Permissions والModule visibility لا تتغير.
