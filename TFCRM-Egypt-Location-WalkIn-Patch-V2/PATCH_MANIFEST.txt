Scope
-----
1. Lead location: Governorate / City or Markaz / Area.
2. Country remains an internal phone-country value; Lead UI uses Egypt location instead.
3. New Lead phone defaults to Egypt (+20), with Egypt-first normalization while preserving historical Saudi formats.
4. Entry Mode is independent from Campaign attribution: WalkIn / Remote.
5. Walk-in requires selecting a Branch; Campaign stays optional only for Walk-in and required for Remote leads.
6. Branch Master in Admin Settings: code, Arabic/English name, governorate, city, area, address, active/inactive.
7. Lead filters: Governorate, City, Area, Entry Mode, Branch; filters stay integrated with existing URL/session behavior.
8. Client Pool receives the same location/entry fields, validation, display, filters, and Excel-current-filter support.
9. Lead -> Client automatic conversion preserves location, Entry Mode, and Walk-in Branch.
10. Lead Profile and Client Profile can display/edit the new fields and show the Branch name.
11. Historical inactive branches remain readable/filterable; branch create/update stays Admin-only.
12. Database migration is idempotent and adds indexed fields + crm_branches table without deleting existing data.
